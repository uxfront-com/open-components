Next, let's look at how developers use the Select. You give it a list of options and a `name`, put it in a Field, and bind its value only when your code needs to read it.

::framework-switcher
#react
```tsx
import { useState } from "react";
import { Field } from "@/components/Field";
import { Select } from "@/components/Select";

const countries = [
  { value: "fr", label: "France" },
  { value: "es", label: "Spain" },
  { value: "nz", label: "New Zealand" },
];

export function Shipping() {
  const [country, setCountry] = useState<string>();

  return (
    <Field label="Country">
      <Select id="country" name="country" options={countries} placeholder="Choose a country" value={country} onChange={(event) => setCountry(event.target.value)} />
    </Field>
  );
}
```

```js [select.js]
// Adds what the browser leaves out to every .select, the way the reference implementation
// does: the keyboard model, typeahead, the panel, chips, announcing a removal and moving id
// and ARIA to whichever control is active. The <select> does the form's work, so submitting and reset need none of
// this. CSS alone decides what paints, before this runs. Browsers without CSS anchor
// positioning need place() from the reference implementation too.
const media = matchMedia("(pointer: coarse)");
const MOVED = ["id", "aria-describedby", "aria-invalid", "aria-label", "aria-labelledby"];
let count = 0;

// One polite live region for the page, there before anything is announced, since screen
// readers only announce changes to a region that's already in the page.
const region = document.createElement("div");
region.setAttribute("role", "status");
region.style.cssText = "position:absolute;width:1px;height:1px;margin:-1px;overflow:hidden;clip-path:inset(50%);white-space:nowrap";
document.body.append(region);
function announce(message) {
  const node = document.createElement("div");
  node.textContent = message;
  region.append(node);
  setTimeout(() => node.remove(), 5000);
}

for (const root of document.querySelectorAll(".select")) {
  const select = root.querySelector("select");
  const control = root.querySelector('button[role="combobox"]');
  const value = control.querySelector('[data-slot="value"]');
  const panel = root.querySelector('[data-slot="panel"]');
  const rows = [...panel.querySelectorAll('[role="option"]')];
  // The panel's rows, in step with the <select>'s options, leaving out the one that stands for nothing.
  const items = [...select.options].filter((option) => !option.hidden);
  const placeholder = value.dataset.placeholder !== undefined ? value.textContent : "";
  const native = () => root.hasAttribute("data-native") && media.matches;
  const anchor = `--select-${++count}`;
  root.style.setProperty("anchor-name", anchor);
  panel.style.setProperty("position-anchor", anchor);

  let open = false;
  let active = -1;
  let typed = "";
  let timer;
  let fromLabel = false;
  let pressedWhileOpen = false;

  // Everything that changes moves as attributes, on the control that's in use.
  function moveAttributes() {
    const [from, to] = native() ? [control, select] : [select, control];
    for (const name of MOVED) {
      if (!from.hasAttribute(name)) continue;
      to.setAttribute(name, from.getAttribute(name));
      from.removeAttribute(name);
    }
    if (native()) {
      select.dataset.slot = "control";
      select.removeAttribute("tabindex");
      select.removeAttribute("aria-hidden");
      delete control.dataset.slot;
    } else {
      select.dataset.slot = "native";
      select.tabIndex = -1;
      select.setAttribute("aria-hidden", "true");
      control.dataset.slot = "control";
    }
  }

  function renderChips() {
    root.querySelector('[data-slot="chips"]')?.remove();
    if (!select.multiple || !picked().length) return;
    const chips = document.createElement("div");
    chips.dataset.slot = "chips";
    for (const item of picked()) {
      const chip = document.createElement("span");
      chip.dataset.slot = "chip";
      const label = document.createElement("span");
      label.dataset.slot = "chip-label";
      label.textContent = item.label;
      const remove = document.createElement("button");
      remove.type = "button";
      remove.dataset.slot = "chip-remove";
      remove.setAttribute("aria-label", `Remove ${item.label}`);
      remove.textContent = "×";
      remove.addEventListener("click", () => {
        const index = picked().indexOf(item);
        item.selected = false;
        changed();
        announce(`${item.label} removed`);
        (root.querySelectorAll('[data-slot="chip-remove"]')[index] ?? control).focus();
      });
      const icon = iconOf(item);
      chip.append(...(icon ? [icon] : []), label, remove);
      chips.append(chip);
    }
    control.after(chips);
  }

  const picked = () => items.filter((item) => item.selected);
  // An option's icon, from its row in the panel, for the field and its chip.
  const iconOf = (item) => rows[items.indexOf(item)]?.querySelector('[data-slot="icon"]')?.cloneNode(true);

  // Shows what the <select> holds.
  function render() {
    const names = picked().map((item) => item.label);
    value.textContent = names.length > 3 ? `${names.length} selected` : names.join(", ") || placeholder;
    if (names.length) delete value.dataset.placeholder;
    else value.dataset.placeholder = "";
    value.toggleAttribute("data-chips", select.multiple && names.length > 0);
    control.querySelector(':scope > [data-slot="icon"]')?.remove();
    const icon = !select.multiple && picked()[0] && iconOf(picked()[0]);
    if (icon) value.before(icon);
    rows.forEach((row, index) => row.setAttribute("aria-selected", String(items[index].selected)));
    renderChips();
  }

  function changed() {
    render();
    select.dispatchEvent(new Event("input", { bubbles: true }));
    select.dispatchEvent(new Event("change", { bubbles: true }));
  }

  function highlight(index) {
    rows[active]?.removeAttribute("data-active");
    active = index;
    const row = rows[active];
    if (open && row) {
      row.dataset.active = "true";
      control.setAttribute("aria-activedescendant", row.id);
      row.scrollIntoView({ block: "nearest" });
    }
  }

  function show(to) {
    if (open || control.disabled || control.getAttribute("aria-readonly") === "true" || native()) return;
    const picks = items.findIndex((item) => item.selected);
    panel.showPopover();
    highlight(to ?? (picks >= 0 ? picks : first()));
  }
  function hide() {
    if (open) panel.hidePopover();
  }

  const enabled = (index) => items[index] && !items[index].disabled;
  function step(from, by) {
    for (let index = from + by; index >= 0 && index < items.length; index += by) if (enabled(index)) return index;
    return from;
  }
  const first = () => step(-1, 1);
  const last = () => step(items.length, -1);

  function pick(index) {
    const item = items[index];
    if (!item || item.disabled) return;
    if (select.multiple) {
      item.selected = !item.selected;
      changed();
      return;
    }
    hide();
    if (!item.selected) {
      item.selected = true;
      changed();
    }
  }

  function search(key) {
    clearTimeout(timer);
    timer = setTimeout(() => (typed = ""), 500);
    const letter = key.toLowerCase();
    const repeating = typed && [...typed].every((character) => character === letter);
    typed += letter;
    const text = repeating ? letter : typed;
    const start = active + (text.length === 1 ? 1 : 0);
    for (let offset = 0; offset < items.length; offset++) {
      const index = (start + offset) % items.length;
      if (enabled(index) && items[index].label.toLowerCase().startsWith(text)) return highlight(index);
    }
  }

  panel.addEventListener("beforetoggle", (event) => {
    open = event.newState === "open";
    root.dataset.state = open ? "open" : "closed";
    control.setAttribute("aria-expanded", String(open));
    if (open) panel.setAttribute("aria-label", control.labels[0]?.textContent ?? control.getAttribute("aria-label") ?? "");
    else control.removeAttribute("aria-activedescendant");
  });
  panel.addEventListener("mousedown", (event) => event.preventDefault());
  rows.forEach((row, index) => row.addEventListener("click", () => pick(index)));

  document.addEventListener(
    "click",
    (event) => {
      if (event.target === control) return;
      fromLabel = event.target.closest?.("label")?.control === control;
    },
    true,
  );
  control.addEventListener("pointerdown", () => (pressedWhileOpen = open));
  control.addEventListener("click", () => {
    control.focus();
    if (fromLabel || pressedWhileOpen) {
      fromLabel = pressedWhileOpen = false;
      return;
    }
    open ? hide() : show();
  });
  control.addEventListener("keyup", (event) => event.key === " " && event.preventDefault());
  control.addEventListener("blur", hide);
  control.addEventListener("keydown", (event) => {
    if (control.getAttribute("aria-readonly") === "true") return;
    const { key } = event;
    const printable = key.length === 1 && !event.ctrlKey && !event.metaKey;
    const handled = () => event.preventDefault();
    if (!open) {
      if (key === "Backspace" && select.multiple && picked().length) {
        handled();
        const item = picked().at(-1);
        item.selected = false;
        changed();
        announce(`${item.label} removed`);
      }
      else if (key === "ArrowDown" || key === "Enter" || key === " ") (handled(), show());
      else if (key === "ArrowUp" || key === "Home") (handled(), show(first()));
      else if (key === "End") (handled(), show(last()));
      else if (printable) {
        handled();
        show();
        // With nothing picked, the first option is only a default, and a letter can land on it.
        if (picked().length) return search(key);
        const start = active;
        rows[start]?.removeAttribute("data-active");
        active = -1;
        search(key);
        if (active < 0) highlight(start);
      }
      return;
    }
    if (key === " " && typed) (handled(), search(key));
    else if (key === "ArrowDown") (handled(), highlight(step(active, 1)));
    else if (key === "ArrowUp" && event.altKey) (handled(), select.multiple || pick(active), hide());
    else if (key === "ArrowUp") (handled(), highlight(step(active, -1)));
    else if (key === "Home") (handled(), highlight(first()));
    else if (key === "End") (handled(), highlight(last()));
    else if (key === "PageDown" || key === "PageUp") {
      handled();
      let index = active;
      for (let moved = 0; moved < 10; moved++) index = step(index, key === "PageDown" ? 1 : -1);
      highlight(index);
    } else if (key === "Enter" || key === " ") (handled(), pick(active));
    else if (key === "Tab") (select.multiple || pick(active), hide());
    else if (key === "Escape") (handled(), event.stopPropagation(), hide());
    else if (printable) (handled(), search(key));
  });

  // If the browser focuses the hidden <select> to report a problem, focus moves on at once.
  select.addEventListener("focus", () => native() || control.focus());
  select.addEventListener("change", render);
  select.form?.addEventListener("reset", () => setTimeout(render));
  media.addEventListener("change", () => (hide(), moveAttributes()));

  // A press on a chip's remove button in the server's markup, and every chip, comes from here.
  moveAttributes();
  render();
}
```

## Consistent

The Select uses the names the other form controls use, so knowing one means knowing them all: the same `size` scale as the Input, `disabled`, `readonly`, `required`, `placeholder` and `name`, and `aria-invalid` rather than an `invalid` prop. Like the Input, classes and styles go on the root, which draws the field, and everything else on the control, including `id` and ARIA. Unlike them, `name`, `form` and `autocomplete` go on the `<select>` in both renderings, along with `change` and `input`, since that's what forms read.

| Prop            | Type                          | Default | Notes                                                         |
| --------------- | ----------------------------- | ------- | ------------------------------------------------------------- |
| `options`       | `SelectItem[]`                | none    | Required. Options, groups and separators                      |
| `value`         | `string`, or `string[]`       | none    | The value, bound or not, an array with `multiple`             |
| `multiple`      | `boolean`                     | `false` | Picks any number of values, each a chip                       |
| `placeholder`   | `string`                      | none    | Shown while nothing is picked, and never a value              |
| `size`          | `xs`, `sm`, `md`, `lg`, `xl`  | `md`    | The Input's five sizes                                        |
| `disabled`      | `boolean`                     | `false` | On both controls, and leaves its form                         |
| `readonly`      | `boolean`                     | `false` | Stays in its form, and turns off `nativeOnTouch`              |
| `required`      | `boolean`                     | `false` | The Field sets this                                           |
| `nativeOnTouch` | `boolean`                     | `true`  | Shows the native `<select>` on a coarse primary pointer       |
| `removeLabel`   | `(label: string) => string`   | "Remove France" | A chip's remove button's name                         |
| `removedLabel`  | `(label: string) => string`   | "France removed" | What screen readers hear after a removal             |
| `countLabel`    | `(count: number) => string`   | "4 selected" | The value read out past three                            |

`nativeOnTouch` is the one new name, so it says when it applies and what it does. Booleans that default to `true` have a precedent in the Popover's `arrow`, and we turn it off with `false` the same way.

An item with a `value` is an option, one with `options` is a group, and one with `separator` is a separator. A few names differ by framework, each for that framework's reason. React and Solid pass the `value` slot as `renderValue`, since `value` is already the value, and `group-label` as `groupLabel`. Angular puts `id` and `name` on the `<select>` inside its directive, so the label's `for` finds a real control, and uses `(ngModel)` for the value.

## Composable

Put the Select in a [Field](/docs/components/field), and it gets its label, hint, error, `required`, `disabled` and `size` without any wiring. It takes the same text-control path through the Field as an Input does, in both renderings, since it's the same component either way.

The slots let you change what's inside each part without giving up how it behaves. The `leading`, `arrow` and `separator` slots take content, while `value`, `option`, `chip`, `group-label` and `icon` hand you what to render, and the `option` slot keeps the check mark beside it and the `chip` slot keeps the remove button.

::framework-switcher

| ------------- | ------------------------------------------------ | ---------------- |

## Controllable

Bind the value when your code reads it, and leave it unbound when the form is all you need. The `<select>` holds it either way, so an unbound Select still submits and resets.

::framework-switcher
#react
```tsx
// Controlled: your state decides.
<Select id="country" name="country" options={countries} value={country} onChange={(event) => setCountry(event.target.value)} />
// Uncontrolled: the Select keeps its own, and its form submits it.
<Select id="country" name="country" options={countries} defaultValue="fr" />
```

```vue
<!-- Controlled: your state decides. -->

<!-- Uncontrolled: the Select keeps its own, and its form submits it. -->
<Select id="country" name="country" :options="countries" value="fr" />
```

```angular-html
<!-- Controlled: your state decides. -->
<div appSelect [options]="countries"><select id="country" name="country" [(ngModel)]="country"></select></div>
<!-- Uncontrolled: the Select keeps its own, and its form submits it. -->
<div appSelect [options]="countries" value="fr"><select id="other" name="other"></select></div>
```

#solid
```tsx
{/* Controlled: your state decides. */}
<Select id="country" name="country" options={countries} value={country()} onChange={(event) => setCountry(event.target.value)} />
{/* Uncontrolled: the Select keeps its own, and its form submits it. */}
<Select id="country" name="country" options={countries} value="fr" />
```

#astro
```astro
<!-- Astro renders it once on the server, so it starts from value, and the form submits what people pick. -->
<Select id="country" name="country" options={countries} value="fr" />
```

#vanilla
```html
<!-- The selected option is the value, which the script keeps in step with the control. -->
<option value="fr" selected>France</option>
<script>
  const country = document.querySelector("#country").value;
</script>
```
::

`change` and `input` fire from the `<select>`, so a listener on the Select or on its form hears both a picker choice and a selection in the panel, with the value already updated. A ref gets you both controls, through `control` and `select`, for focusing it from your own code.

## DX Checklist

| Rule                     | Level  | Scope     | Requirement | Basis | Check |
| ------------------------ | ------ | --------- | ----------- | ----- | ----- |
| `select/options-prop`    | Must   | Component | Options, groups and separators are one typed `options` list, the same in both renderings | Open Components | Unit test, Type check |
| `select/value`           | Must   | Component | The value is a string, or an array with `multiple`, bound or unbound | Open Components | Unit test |
| `select/typed`           | Should | Component | Its props and slots are typed, and the option types are exported | Open Components | Type check |
| `select/same-names`      | Should | Component | It uses the names and sizes the other form controls use | Open Components | Review |
| `select/attributes`      | Must   | Component | Classes and styles go on the root, form attributes on the `<select>`, and the rest on the active control | Open Components | Unit test |
| `select/in-a-field`      | Must   | Both      | In a Field, it takes the label, description, invalid and disabled state in both renderings | WCAG 1.3.1 (A) | Unit test |
| `select/slots`           | Should | Component | Each part has a slot or tokens to restyle it, and the check mark and remove button stay | Open Components | Unit test |
| `select/translatable`    | Should | Component | Every string it announces or adds comes through a prop | Open Components | Unit test |
