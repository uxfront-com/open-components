The Button's page had grown to about 35,000 tokens, so finding your way back to one section meant a long scroll. It's now an Overview, with the checklist, the FAQ and the sources, and a page for each layer and one for its reference implementation, all under Button in the sidebar.

## Improved

- The User Interface, User Experience, Developer Experience and Agentic Experience sections, and the reference implementation, each have a page of their own, linked from the Overview and from each other.
- Links to the Button's sections from before the split, like one to its loading state, still take you to the right section on its new page.
- Agents read the Button as before: `/raw/docs/components/button.md`, its contract and the MCP server still serve it as one page.
