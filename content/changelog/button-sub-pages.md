The Button's page had grown to about 35,000 tokens, so finding your way back to one section meant a long scroll. It's now an Overview, with the playground, At a glance, the reference implementation and the sources, and a page for each layer, all under Button in the sidebar.

## Improved

- The User Interface, User Experience, Developer Experience and Agentic Experience sections each have a page of their own, with the layer's rules and the questions it answers, and the Overview links each one from a card.
- In the sidebar, Button links to its Overview, and the arrow beside it opens and closes the list of its layers, which stays open while you read them.
- Links to the Button's sections from before the split, like one to its loading state, still take you to the right section on its new page.
- Agents read the Button as before: `/raw/docs/components/button.md`, its contract and the MCP server still serve it as one page.
