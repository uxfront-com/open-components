# Open Components agent plugin

The [Open Components](https://opencomponents.dev) standard for UI components, in your agent. It's an [Agent Plugin](https://agent-plugins.org), so it works in any client that supports the format.

- `skills/` holds four [Agent Skills](https://agentskills.io), which your agent picks up on its own when a task calls for them: `build-component`, `review-component`, `review-usage` and `adopt-token-paths`.
- `mcp.json` connects the [Open Components MCP server](https://opencomponents.dev/docs/getting-started/mcp-server), which serves the contracts, every rule and the docs, a section at a time. It's free, with no sign-in.

The [Agent Plugin](https://opencomponents.dev/docs/getting-started/agent-plugin) page shows how to install it in your client.
